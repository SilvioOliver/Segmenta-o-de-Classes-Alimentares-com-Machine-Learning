# Projeto de Clusterização de Clientes

## 📌 Descrição
## Projeto 7 - Segmentando Classes Alimentares - Alimentação

## 🧠 Objetivo
Este projeto tem como objetivo aplicar técnicas de clusterização para segmentar clientes, permitindo gerar insights estratégicos e apoiar decisões de negócio.

## 🛠️ Tecnologias Utilizadas
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn

## 🔍 Etapas do Projeto
- Carregamento e exploração dos dados
- Limpeza e pré-processamento
- Engenharia de atributos
- Aplicação de algoritmos de clusterização (ex: K-Means)
- Avaliação dos clusters
- Visualização dos resultados

## 📊 Resultados Esperados
- Identificação de grupos distintos de clientes
- Melhor entendimento do comportamento do cliente
- Apoio a estratégias de marketing e negócio

## ▶️ Como Executar
1. Clone este repositório
2. Instale as dependências:
```bash
pip install -r requirements.txt
```
3. Execute o notebook:
```bash
jupyter notebook
```

## 📁 Estrutura do Projeto
- `Clusterizacao_Clientes_TCD.ipynb` → Notebook principal com toda a análise
